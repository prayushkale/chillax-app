# Security policy

Please do not open a public issue for a vulnerability. Use GitHub's private vulnerability
reporting: go to the **Security** tab of this repository and choose **Report a vulnerability**.

Chillax runs coding agents with access to your repositories and serves a local web UI on
`127.0.0.1`. Reports about agent permission handling, the local server (host check, tokens),
secrets reaching logs or the event store, and command execution are the most useful.

Only the latest commit on `main` is supported.
